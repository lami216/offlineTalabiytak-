# Clean Windows test checklist

- Disconnect networking; install `Talabiytak-Setup.exe` on Windows 10 and 11 without Python/MongoDB.
- Confirm Start/Desktop shortcuts, embedded window, loopback-only listener, and no outbound traffic.
- Confirm an empty dashboard and newly created local folders/database.
- Import XLSX, verify original bytes, duplicate filters, naming/ignoring, product search and cleanup.
- Create/reorder an order, set quantities, export image-bearing Arabic Excel and verify pricing RMB/CBM.
- Restart and verify all records/images remain; attempt a second instance and verify the Arabic warning.
- Upgrade over the installation and verify persistence.
- Uninstall with deletion unchecked, reinstall, and verify persistence.
- Uninstall in a disposable profile with deletion checked and confirm explicit data removal.
